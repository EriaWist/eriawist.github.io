隱私權政策

生效與最後更新日期：2026 年 11 月 17 日

你的文件，由你掌握。TrellisMD 在裝置上處理文字編輯與預覽，不需要建立 TrellisMD 帳號。

我們如何處理資料

TrellisMD 未整合廣告、跨 App 追蹤或第三方使用分析 SDK，也不會自動將文件、草稿或診斷紀錄上傳至開發者的伺服器。我們不出售使用者資料。

使用者主動分享檔案、開啟區網伺服器、載入外部網頁資源或提交支援請求時，資料可能傳送至你選擇的裝置、服務或支援平台，詳見下列說明。

1. 文件、資料夾與本機草稿

App 讀取你選擇開啟的文字檔，並在你儲存時寫回原始檔案。為恢復編輯中的內容，App 會在自身的本機文件空間保存草稿；也會在裝置上保存已授權資料夾的存取書籤，供下次開啟使用。這些資料用於提供編輯功能，不會自動傳送給開發者。

若你選擇 iCloud Drive 或其他雲端檔案提供者中的資料夾，該服務可能依其設定同步檔案。裝置與 App 資料也可能依你的系統設定納入 Apple 備份；這些服務由其提供者管理。

2. Markdown 與 HTML 預覽

Markdown 渲染程式、Mermaid 與 KaTeX 字型隨 App 提供，基本預覽不需將文件傳至遠端轉換服務。不過，文件內的遠端圖片、連結、HTML 腳本或其他外部資源，可能在預覽或點擊時向相關網站提出網路請求。該網站可能取得 IP 位址、請求網址及其他一般連線資訊，並可能使用 Cookie 或 WebKit 網站儲存空間。相關處理由該網站的政策規範。

3. 區網靜態網站分享

只有當你主動啟動區網 Server 時，App 才提供所選資料夾及其子資料夾中的靜態檔案讀取服務。能連線到該服務的裝置，可透過已知路徑讀取分享範圍內的檔案。此功能使用 HTTP，沒有內建登入驗證或 TLS 傳輸加密；請僅在信任的網路使用，並選擇不含私人資料的分享資料夾。

區網服務需讓 App 保持前景；你可手動停止，切換至背景也會停止。接收者已下載的檔案不會因此被刪除。

4. 診斷紀錄

為協助排查網頁問題，App 會在本次執行的記憶體內保留最近最多 500 筆診斷紀錄，並輸出至裝置的系統日誌。紀錄可能包含本機檔案路徑、頁面與資源網址、連線端點（例如區網 IP）、HTTP 請求路徑、錯誤訊息、App 與系統版本及載入狀態。

診斷功能不會刻意記錄完整文件原始碼或 HTTP 回應內容，但網址、檔名及網頁產生的錯誤訊息仍可能帶有敏感資訊。紀錄不會自動上傳；只有在你主動使用分享功能並選擇接收者時才會傳出。分享前請先檢查並遮蔽敏感內容。系統日誌的保存由作業系統管理。

5. 支援聯絡與第三方平台

若你透過 GitHub Issues 聯絡維護者，我們會收到你自願提交的帳號名稱、問題描述、附件及其他資訊，並用於處理請求。GitHub Issues 通常為公開內容，請勿貼上私人文件、密碼、存取權杖或完整的敏感紀錄。GitHub 的資料處理適用於 GitHub 隱私權聲明。

本隱私權與支援網站本身不載入分析工具、外部字型或追蹤腳本。若網站由 GitHub Pages 提供，GitHub 仍可能為提供與維護服務而處理一般訪問紀錄，例如 IP 位址。

6. 保存、刪除與你的選擇

你可以自行編輯或刪除文件。草稿在文件成功儲存或選擇捨棄並關閉時移除；未儲存草稿可能保留供下次恢復。刪除 App（而非僅卸載 App）可移除 App 沙盒內的資料；外部資料夾、雲端檔案、備份，以及已分享給他人的副本，需在相應位置另行管理。WebKit 網站資料可能保存在 App 的網站資料儲存區，並隨 App 資料一同管理。

開發者沒有可供遠端查閱或刪除你本機文件的帳號資料庫。若要詢問你主動提交的支援資料，請使用原支援討論串聯絡；公開內容與平台保留規則仍依 GitHub 的設定與政策處理。

7. 政策更新與聯絡

若資料處理方式改變，我們會更新本頁及上方日期。隱私權問題可透過 TrellisMD GitHub Issues 聯絡維護者 EriaWist。提交時請以不含個人敏感資訊的方式描述問題。
