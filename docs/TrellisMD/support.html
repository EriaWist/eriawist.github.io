TrellisMD 使用支援
iPhone 與 iPad 的 Markdown、文字與 Web 編輯工作區。

聯絡維護者

有使用問題、錯誤回報或功能建議，請透過專案的 GitHub Issues 聯絡 EriaWist。

提交支援請求

提交問題需要 GitHub 帳號。也可以先查看既有問題。討論內容通常公開，請勿附上私人文件或敏感資料。

快速開始

  1. 開啟 Welcome 範例，或點「加入資料夾」，選擇「檔案」App 提供的資料夾。
  2. 選擇文字檔開始編輯；使用右上角儲存按鈕將變更寫回檔案。
  3. Markdown 與 HTML 可切換「編輯／預覽」；iPad 另提供「並排」模式。
  4. 需要區網測試網站時，開啟 HTML 檔案，點右上角 Server 圖示，選擇分享資料夾與 Port 後啟動。

常見問題

支援哪些檔案與裝置？

支援 iOS／iPadOS 17 以上版本。可編輯 UTF-8 純文字檔，Markdown、HTML、CSS、JavaScript 提供基本語法上色。Markdown 與 HTML 提供預覽；PDF、圖片、壓縮檔等二進位檔案不支援文字編輯。

可以離線使用嗎？

本機編輯及 Markdown、Mermaid、KaTeX 基本預覽可離線使用。文件引用的遠端圖片、外部網站及尚未下載的雲端檔案，仍可能需要網路。

為什麼看不到預覽或 Server 按鈕？

只有 Markdown 與 HTML 支援預覽。Server 按鈕只在開啟 HTML／HTM 文件時顯示。iPhone 使用「編輯／預覽」切換；iPad 可選「並排」。

區網網站無法連線或顯示舊內容？

請確認兩台裝置連上同一區網、已允許 App 的區域網路權限，而且 App 保持前景。先儲存檔案，再重新整理。分享根目錄的首頁需命名為 index.html；請確認檔案位於選定分享範圍內。若 Port 被占用，可先停止服務再換一個 Port。部分 Wi-Fi 訪客網路會阻擋裝置彼此連線。

此服務沒有登入驗證，請勿分享含私人資訊的資料夾。切換 App 至背景後服務會停止。

HTML 可以執行 npm 或後端程式嗎？

HTML 預覽可載入前端 JavaScript 與相對路徑資源。區網 Server 提供靜態檔案讀取，不提供 npm、Node.js、PHP、終端機或其他後端程式執行環境。

無法開啟外部資料夾或儲存檔案？

請確認檔案已由雲端服務下載，並嘗試重新加入該資料夾。若檔案已被其他程式修改，App 會拒絕直接覆蓋；請先複製保留目前編輯內容，再重新開啟原始檔案。外部檔案權限與同步行為依提供者而異。

編輯中的內容會自動儲存嗎？

原始檔案需手動儲存。App 會延遲保存本機草稿，重新開啟原檔時可恢復；重要內容仍請定期存檔與備份。關閉未儲存文件時可選擇儲存或捨棄。

網頁預覽空白，如何協助排查？

重現問題後等待約兩秒，關閉網頁，在 Server 設定中開啟「查看網頁診斷紀錄」，點「更新」並檢查內容。若要提供紀錄，請先遮蔽本機路徑、IP、網址參數與其他敏感資訊，再透過支援請求分享必要片段。

回報問題時，請附上

  • App 版本、iOS／iPadOS 版本與裝置型號。
  • 重現步驟、預期結果與實際結果。
  • 不含私人資料的截圖，或可公開的最小範例。
  • 若與網頁有關，請註明使用內嵌預覽、App 內網站或另一台裝置連線。

請勿提交密碼、存取權杖、完整私人文件或未遮蔽的敏感診斷紀錄。隱私權與資料處理方式請參閱隱私權政策。
